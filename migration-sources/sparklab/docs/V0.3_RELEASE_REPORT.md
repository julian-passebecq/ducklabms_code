# DuckLake Data Engineering Lab V0.3 — SparkLab pass

## Product correction

V0.2 over-emphasized interoperability formats. V0.3 returns to the original product thesis: a real DuckLake/Parquet engineering lab designed to train notebook reasoning transferable to Fabric and Databricks.

Iceberg, Avro, Delta and related connectors are moved to an optional Advanced appendix.

## Added

- four Parquet-first case studies: mobility, retail, energy and finance;
- dual SQL/PySpark notebook modes;
- SparkLab page with logical/physical-plan teaching;
- case-specific partition, skew and shuffle evidence;
- broadcast-join reasoning;
- explicit real vs simulated truth boundary;
- Python SparkLab compatibility-layer scaffold;
- profile-driven distributed-runtime estimator;
- DuckDB SQL compiler for the supported SparkLab subset;
- documented Polars role as a real DataFrame engine, not a Spark impersonator.

## Initial SparkLab evidence

Retail profile:

- `silver.orders`: 184,229,821 rows, 26.4 GB;
- customer partition skew ratio: 18.2x;
- `dim_customer_segment`: 6.4 MB broadcast candidate;
- aggregation still produces a wide boundary after the optimized join.

The values are case-profile inputs and must later be generated/verified from the real MotherDuck/DuckLake datasets rather than remain hard-coded.
