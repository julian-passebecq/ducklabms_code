## Reference Retail result

On the Fabric-like profile with AQE enabled:

- baseline SortMerge plan modeled shuffle: ~52.8 GB;
- optimized BroadcastHashJoin + downstream aggregate shuffle: 26.4 GB;
- 1,656 MB hot shuffle partition is detected as skewed;
- AQE splits the hot partition into smaller tasks in the reference model;
- optimized plan has lower modeled wall-clock and SparkLab cost than baseline.
