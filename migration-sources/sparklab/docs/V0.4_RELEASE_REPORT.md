# V0.4 Debug / Test / Improvement Report

## Baseline

V0.3 DuckLake Data Engineering Lab.

## Defects found and fixed

1. **UI/API mismatch for PySpark windows** — notebook samples used `Window`, `row_number`, `lag` and rolling windows while SparkLab did not implement them. Fixed with `WindowSpec`, `Window`, `Expr.over`, ordering and bounded row frames.
2. **Silent compiler omissions** — `withColumn` and dedupe operations were recorded in the logical plan but omitted from generated SQL. They now compile to nested DuckDB-compatible relational SQL.
3. **Case-profile drift** — UI partition/shuffle/skew values did not match `profiles.json`. All four core cases now use aligned statistics.
4. **Retail plan inconsistency** — UI showed a broadcast join but retained a larger pre-optimization shuffle figure. V0.4 shows optimized shuffle and a separate no-broadcast baseline.
5. **Mission navigation mismatch** — Airflow/dbt/Lakehouse/Incident missions opened the notebook. They now route to Pipeline/dbt/Lakehouse/Quality respectively.
6. **Insufficient mission context** — Notebook and SparkLab now surface the active mission/evidence boundary.
