## Environment limitation

The authoring environment could not reach the npm registry, therefore the
full React dependency installation and Vite production build were not run.
The source is structured for standard `npm install && npm run build` once a
registry is available. A dependency-free prototype is included and was used
for interaction/visual QA.

## Engineering correction during QA

The initial example used `CREATE OR REPLACE TABLE silver.trips` while filtering
only one service date. That would have dropped unaffected Silver partitions.
The final mission stages the repaired date in a temporary table and performs a
transactional delete+insert for the affected partition only, preserving all
other Silver data and keeping Bronze immutable.
